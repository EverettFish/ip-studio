# 品牌 Logo 与协作者更新设计

## 目标

用用户提供的双人插画替换侧边栏 `IP Studio` 左侧的黑色通用图标，同时保持现有白底黑字、简洁非衬线界面。原图保留透明云朵轮廓与两位角色，不裁成圆形或方形，作为约 50×41px 的横向品牌徽记。

## 资源与验证

原始 PNG 缩放为 240px 宽的透明 WebP，页面下载体积从约 773KB 降至约 16KB。Logo 使用明确的替代文本，固定宽高避免加载时布局跳动；桌面与移动侧边栏共用同一组件。更新后运行测试、代码检查和生产构建，再通过现有 GitHub Actions 自动发布。

仓库协作方面，向 GitHub 用户 `kevinyoung-kw` 发出 Write 权限邀请。协作者仍需通过功能分支、Pull Request 与 `verify` 自动检查进入受保护的 `main`。
