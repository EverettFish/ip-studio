# 角色锚点、萌粒风与主页鸣谢流程

## 目标

- `Life / Work / Media` 只作为贴纸页的默认主题。
- 用户修改主题后，输出预览、任务名、贴纸页标题和下载文件名使用同一组主题。
- 贴纸页恢复 Skill 规定的 3:4 竖版、顶部 12–16% 标题区和 18 枚贴纸结构。
- 角色锚点强制作为每次生成的 Image 1 与最高优先级身份参考。
- 所有路线固定使用萌粒风，不再提供“保持原画风”或其他画风选项。
- 按 Skill 逐项对齐 11 条路线的数量、比例、透明度、构图和文字约束。
- 抽屉按“输入内容 → 配置问卷 → 核对输出”显示清晰步骤。
- 在主页“今天想做什么”上方加入作者和特别鸣谢头像走马灯；头像昵称整块链接到各自小红书主页，链接文字不直接显示，悬停或键盘聚焦时暂停。

## 数据流

贴纸主题使用可分行或逗号输入的 `themes` 字段。默认值为 `Life / Work / Media` 三行。统一的主题解析函数负责生成预计数量、预览标题、任务标题和提示词中的页眉标题，避免多处各自写死默认值。

角色锚点只在本机保存。前端以独立的 `anchor` 表单字段发送锚点，内容图片以 `sources` 字段发送；服务端拒绝缺少锚点的请求，并始终按 `[anchor, ...sources]` 的顺序提交给图像编辑接口。服务端在每次任务提示之前再次写入不可覆盖的身份与萌粒风规则：先检查 Image 1，锁定完整发型或毛发轮廓、五官、身体比例、服装、配饰和标志配色；后续图片只能控制场景、内容、动作或版式。

文章配图与信息图仍由规划接口生成任务，但规划提示和最终出图接口都重复同一条身份政策。这样即使文章内容包含指令、规划结果遗漏身份描述，最终生成仍以锚点为最高优先级。

## 主页走马灯

作者与鸣谢条放在“今天想做什么”标题上方，使用两份相同列表组成无缝横向循环。每项包含圆形头像、角色标签和昵称，整块使用外链并在新标签页打开。作者 EverettFish 使用“作者”标签，其余六位使用“特别鸣谢”标签。容器左右使用白色渐隐，不显示原始链接；鼠标悬停、键盘聚焦时暂停动画，系统开启减少动态效果时关闭自动滚动并允许横向手动浏览。

## 贴纸页约束

每个主题生成一张 3:4 竖版不透明贴纸页。顶部 12–16% 是连续标题插画区，下面是独立贴纸区。默认正好 18 枚：3 个场景、5 个动作、4 个头像或半身、6 个微型填充；保持独立异形白边、S 形节奏、75–82% 占用率，不使用横版透明散贴或固定的 Life / Work / Media 文案。

## 验证

- 单元测试验证默认三页和自定义主题标题、数量、尺寸、背景与版式提示。
- 单元测试验证所有静态任务都包含锚点身份锁和固定萌粒风锁，且表情包夺舍不再出现可选画风。
- 接口测试与代码检查验证锚点必填、锚点先于内容图、无锚点不允许纯文字生成。
- 检查走马灯七个头像、昵称、链接、重复轨道、悬停暂停和减少动态效果。
- 运行测试、检查代码风格并执行生产构建。
- 发布后打开正式域名确认新版本可用。
