# 贴纸主题与角色锚点流程修复

## 目标

- `Life / Work / Media` 只作为贴纸页的默认主题。
- 用户修改主题后，输出预览、任务名、贴纸页标题和下载文件名使用同一组主题。
- 贴纸页恢复 Skill 规定的 3:4 竖版、顶部 12–16% 标题区和 18 枚贴纸结构。
- 角色锚点支持“转为萌粒风”和“保持原画风”，并在每次生成时明确执行所选模式。
- 抽屉按“输入内容 → 配置问卷 → 核对输出”显示清晰步骤。

## 数据流

贴纸主题使用可分行或逗号输入的 `themes` 字段。默认值为 `Life / Work / Media` 三行。统一的主题解析函数负责生成预计数量、预览标题、任务标题和提示词中的页眉标题，避免多处各自写死默认值。

角色画风模式与锚点一起保存在本机。旧锚点没有该字段时默认使用萌粒风。生成请求在原任务提示前加入明确的锚点渲染规则：萌粒模式只转换笔触与上色方式，不改变身份；原画模式保留锚点媒介与视觉完成度。

## 贴纸页约束

每个主题生成一张 3:4 竖版不透明贴纸页。顶部 12–16% 是连续标题插画区，下面是独立贴纸区。默认正好 18 枚：3 个场景、5 个动作、4 个头像或半身、6 个微型填充；保持独立异形白边、S 形节奏、75–82% 占用率，不使用横版透明散贴或固定的 Life / Work / Media 文案。

## 验证

- 单元测试验证默认三页和自定义主题标题、数量、尺寸、背景与版式提示。
- 单元测试验证两种锚点画风指令。
- 运行测试、检查代码风格并执行生产构建。
- 发布后打开正式域名确认新版本可用。
