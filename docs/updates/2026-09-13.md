# IP Studio 更新日志 · 2026-09-13

这次更新，把大家反馈的「卡在第一步」补上了。

- 没有现成 IP？点击「还没有自己的形象？试一试」，从 3 个可修改的 Demo 开始，描述并生成自己的角色，满意后确认为锚点。
- 批量创作新增「整套统一要求」，可以统一背景、道具，也能按图片序号分别提出要求。
- 贴纸新增透明底选项；表情包默认统一纯白背景，也可选择草地或混合小场景；实拍融合加强坐姿与椅子前后关系的描述。
- 模型配置与创作页增加 Image 2 推荐提示，涉及文字、透明度时更容易判断模型是否适合。继续支持自配 API 与 TokenDance 一键接入。
- 手机端增加生成期间的离页提醒和屏幕常亮请求（浏览器支持时）。已完成图片逐张保存；iOS 后台持续生图仍无法保证，请保持页面前台。
